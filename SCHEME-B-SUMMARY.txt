🎓 已知限制
────────────────────────────────────────────────────────────────────

高德 API 限制:
  • PlaceSearch 可能无法 100% 匹配门店名 (支持回退)
  • 驾车时间需要精确 GPS (±1m，合理降级)
  • API 日限额需监控

功能限制:
  • 仅支持驾车时间 (其他模式可扩展)
  • POI 评价仅来自高德 (可与本地融合)
  • 14 城市需后端数据支持

性能注意:
  • POI 评价不跨会话缓存 (合理)
  • 驾车时间缓存本会话有效 (合理)

📞 技术支持
────────────────────────────────────────────────────────────────────

问题排查:
  1. 高德 API 返回空 → 检查关键词匹配、权限
  2. 驾车时间失败 → 检查 API 密钥、订阅、配额
  3. 城市识别错误 → GPS 精度低或覆盖不足
  4. POI 评价不显示 → PlaceSearch 未授权

环境变量:
  VITE_AMAP_KEY=<your_web_api_key>
  VITE_AMAP_SECURITY_CODE=<optional_security_code>
