# Washjoy 归档

本目录保存项目外部产生的可复用历史资料和验收产物，按来源分组。

- `amap/`：高德地点搜索原始响应（不含凭据）。
- `assets/`：曾放在临时目录、可作为仓库素材源的图片。
- `screenshots/`：浏览器验收截图。
- `test-artifacts/`：Playwright/浏览器验收记录。
- `build-logs/`：构建和浏览器调试日志。
- `deployment/`：当前线上静态发布文件的只读快照，不包含 `private/`、`uploads/` 或运行数据库。

生产数据库、数据库快照、用户上传、Cookie、环境变量和密钥仍保留在其受保护的运行目录，不复制到源码归档。
